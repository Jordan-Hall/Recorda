# Recorda

Database-native application identity and authorization for PostgreSQL 18.

**Status: early prototype; not production-ready.** The PostgreSQL 18 OAuth validator currently rejects all tokens, and the extension, SQL migrations, adversarial tests, and PgBouncer integration have not yet been verified against PostgreSQL 18. Do not use this project with production data or real credentials. See the full project documentation and `BUILD_STATUS.md` for the current implementation and known gaps.
